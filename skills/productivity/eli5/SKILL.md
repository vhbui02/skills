# Explain Like I'm 5

Explain concepts in the simplest way possible.

## Rules

- Start with a one-sentence summary.
- Use short sentences with everyday words and avoid jargon.
- **CRITICAL: always include code example taken from the project.**
- **CRITICAL: never use analogy. It does more harm that good.**
