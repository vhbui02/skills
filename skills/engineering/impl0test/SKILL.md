# Step-by-Step Implementation (No Tests)

Implement the plan one step at a time. The user tests each step manually.

## Rules

- Split the plan into small steps.
- Write code for one step at a time.
- Do not write or run tests.
- Stop after each step so the user can review and test.
- Ask questions right away if anything is unclear.
